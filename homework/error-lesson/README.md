# Занятие 2. Абсолютная и относительная погрешность

На учебной таблице сравнил четыре измерения с эталонами. Абсолютная погрешность — модуль разности в метрах. Относительная — абсолютная погрешность, делённая на модуль эталона. Для процентов результат умножается на 100.

| Показание | Измерение, м | Эталон, м | Абс., м | Отн., % |
|---|---:|---:|---:|---:|
| A | 2,48 | 2,50 | 0,02 | 0,80 |
| B | 0,247 | 0,250 | 0,003 | 1,20 |
| C | −0,51 | −0,50 | 0,01 | 2,00 |
| D | 0,01 | 0 | 0,01 | не определена |

У B абсолютная погрешность меньше, чем у A, а относительная больше из-за меньшего эталона. Отрицательное эталонное значение в C не делает погрешность отрицательной. Для D деление на ноль невозможно, поэтому сравниваю только абсолютную погрешность.
